## 二、录制方式与所需权限

### 采用的录制方式

没有使用系统级屏幕录制，而是用 **Playwright 驱动本机 Edge（无头模式）录制页面视口**：

1. 无头 Edge 加载 `http://localhost:5001`；
2. Playwright 以 25fps 录制页面画面；
3. 脚本按预设节奏依次操作各功能，并注入一枚**虚拟鼠标指针 + 点击水纹**（Playwright 默认不录制系统光标，注入后观众能看清每一步点了哪里）；
4. 录制完成后用 ffmpeg 将 webm 转为通用 mp4。

这样做的好处：画面只包含应用本身，不会录进桌面、任务栏、聊天软件等无关内容，分辨率固定、画面稳定。

### 实际需要的权限（均已具备，无需您额外授权）

| 权限 | 用途 | 状态 |

| 写入项目 `demo/` 目录 | 保存视频、截图、导出文件 | 已具备 |
| 网络下载临时工具（playwright、ffmpeg-static） | 录制与转码 | 已执行，安装在临时目录 |

## 四、过程中处理的问题

| 现象 | 处理 |
| --- | --- |
| Playwright 录不到系统鼠标指针 | 注入虚拟箭头光标 + 点击水纹，跟随真实鼠标事件 |
| Next.js 开发浮标出现在左下角（会入镜） | 录像期间注入 `nextjs-portal{display:none}` 隐藏 |
| 关闭浏览器时 Playwright 偶发内部 `TargetClosedError` | 增加 unhandledRejection 过滤，不影响已落盘的视频 |
| 首版时长仅 1 分 46 秒 | 放慢每步节奏、补充拖拽上传/分组内新建/右栏滚动/滑块拖动等段落，扩展到 3 分 34 秒 |
| 首版收尾等待了不存在的元素，末尾静止约 60 秒 | 修正收尾步骤，成片无静止尾帧 |
| 自带 ffmpeg 仅支持 VP8 | 改用 ffmpeg-static 的 libx264 转 H.264 mp4 |

## 五、如何复现录制

```powershell
# 1) 启动开发服务器（Windows 下使用 webpack 模式，避免 Turbopack 崩溃）
pnpm run dev        # 端口 5001

# 2) 临时安装录制依赖（不写入项目 package.json）
New-Item -ItemType Directory -Force .demo-tools | Out-Null
Set-Location .demo-tools
'{"name":"demo-tools","private":true,"type":"module"}' | Set-Content package.json
$env:PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD="1"
npm i playwright@1.49.1 ffmpeg-static --no-audit --no-fund
node node_modules/playwright/cli.js install ffmpeg
Set-Location ..

# 3) 运行录制脚本（脚本需位于 .demo-tools 内，输出仍写入项目 demo/）
Copy-Item demo/record-demo.mjs .demo-tools/record.mjs -Force
node .demo-tools/record.mjs

# 4) 转码为 mp4
.demo-tools/node_modules/ffmpeg-static/ffmpeg.exe -y -i demo/溯研功能演示.webm `
  -c:v libx264 -preset medium -crf 20 -pix_fmt yuv420p -movflags +faststart -an `
  demo/溯研功能演示.mp4
```

脚本使用系统 Edge（`channel: 'msedge'`），无需额外下载 Chromium；所有操作均为真实点击/输入，不是视频剪辑拼接。

## 六、已知限制

- 当前为**演示模式**（未配置 Coze Token），Agent 执行数据由本地编排模拟；真实联调需按 `.env.local` 配置 Coze 凭证。
- 按要求**不加字幕、不加旁白**，功能含义依赖画面中的界面文字。
- 浏览器原生 `confirm/alert` 弹窗不属于页面渲染内容，不会进入录制画面，因此「删除任务」「删除分组」未在视频中演示；这两项已在 `TEST_REPORT.md` 的手工用例中验证通过。
- 演示只覆盖桌面端 1600×900；移动端与 1366×768 的回归见 `TEST_REPORT.md` 未覆盖项。
